Netlify & Supabase Anleitung

1 Supabase Tabelle erstellen

Führe folgendes SQL-Skript im Supabase SQL Editor aus: 

create table counter (
  id int primary key,
  value int default 0,
  text_value text default ''
);

insert into counter (id, value, text_value) 
values (1, 0, 'Hallo Welt!') 
on conflict (id) do nothing;

alter table counter enable row level security;

create policy "Allow public access" on counter for all using (true) with check (true);

2 Auf Netlify hochladen

  1. Speichere diesen Code als index.html.
  2. Gehe zu Netlify.com.
  3. Ziehe den Ordner mit der Datei in das Upload-Feld.
